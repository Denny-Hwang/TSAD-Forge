# Leaderboard — VUS-PR

!!! warning "Lite profile — preview"
    These numbers come from the **lite** subset (CI-sized: a handful of entities per dataset), not the full benchmark matrix. Means are shown with entity-bootstrap 95% CIs and an `entities` count — a mean over few entities with a wide CI is weak evidence. Do not quote ranks from this page without those qualifiers.

Primary metric: **VUS-PR** (Paparrizos et al., VLDB 2022). Values are seed averages; cell shading follows the metric value, row tint and badge follow the generation. PA-F1 is intentionally not shown (CLAUDE.md §4).

Friedman test across the 37 models with complete coverage of the 21 shared entities: **p = 4.16e-14** — model ranking differences are statistically significant overall; see the critical-difference diagram for which pairs are separable.

**Coverage differs across models** (4–21 entities). `mean vus_pr` averages over *each model's own* entities and is not a fair cross-model comparison; `shared-entity` averages only over the **4** entities every model was run on, and `norm. rank` is the per-entity rank rescaled to [0, 1] (0 = best) so that entities with different numbers of competitors are comparable.

`fidelity` (see the [model catalog](../models.md)): **simplified** rows measure this repository's simplified reimplementation, not the original method.
